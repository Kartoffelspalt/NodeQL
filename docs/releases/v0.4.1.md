# NodeQL 0.4.1

NodeQL 0.4.1 is a substantial update to the visual SQLite workbench. It makes
query construction more expressive, query results more portable, and the
desktop workspace more polished.

## Visual SQLite improvements

- A built-in SQLite function catalog is now available for visual queries.
- Date and time conversions can be created visually with
  `datetime(timestamp, 'unixepoch')`.
- SELECT columns can receive individual aliases directly in the column picker.
- Multiple aliased columns are supported in the same query.
- Compiler improvements qualify columns where necessary, avoiding ambiguous
  column errors when joined tables contain the same column name.
- Nested column and function reporters remain clickable and editable.

## Results, preview, and export

- Query-result tables can be opened in fullscreen.
- Results can be exported as CSV, JSON, or TSV for use in other applications.
- SQL command output and result tables now share one consistent visual style.
- The database browser and live preview received a broader workflow polish.

## Workspace and settings

- Resizable workspace areas now use a responsive overlay while dragging and a
  smooth cross-platform transition when released.
- Settings open fullscreen and are organized into Accessibility, Motion,
  Display, and Personalization sections.
- The SQLite Workshop and its isolated practice database have been expanded
  and refined.

## Fixes

- Autosave starts reliably after project changes.
- Fixed invalid rollback arguments during query execution.
- Fixed scrollbar controller assertions in resizable layouts.
- Fixed Material ink warnings for selectable repository entries.
- Improved Linux and Windows desktop runner behavior.
