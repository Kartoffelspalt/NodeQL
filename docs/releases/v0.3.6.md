# NodeQL 0.3.6

NodeQL 0.3.6 expands the database browser with two focused ways to create
SQLite tables: a guided graphical workflow for Simple Mode and complete
`CREATE TABLE` control for Advanced Mode.

## Graphical table creation

- Simple Mode now includes a graphical Create Table form.
- Tables can contain multiple columns with `INTEGER`, `TEXT`, `REAL`,
  `NUMERIC`, or `BLOB` affinity.
- Each column can be configured as a primary key, required (`NOT NULL`), or
  unique.
- A live SQLite preview shows the exact statement before it is executed.
- The form validates table names, column names, and duplicate columns before
  creating the table.

## Advanced SQLite workflow

- Advanced Mode includes a raw editor for complete `CREATE TABLE` statements.
- Successful schema changes refresh the browser immediately so the new table
  can be inspected without closing the dialog.
- Multi-statement execution now preserves dependencies between statements and
  restores the database snapshot if execution fails.
- SQLite itself is used to distinguish read-only statements from database
  writes more reliably.

## Interface and access

- The database browser remains intentionally hidden from the visible
  workbench UI and opens with the `D`, `B`, `B` keyboard sequence.
- The separate Custom SQLite button remains visible but disabled in this
  release.
- Object metadata and pagination controls adapt more cleanly to narrow dialog
  widths.

## Version

- Application version: `0.3.6+1`
