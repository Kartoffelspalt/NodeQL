04 / How it works


Three steps.
One workflow.


Designed to make the structure of a query visible, not just the result.




01
Choose blocks
Search the palette by command or browse its categories, then drag blocks into the workspace.
SELECTWHEREJOIN


02
Compose your query
Connect blocks and fill in their fields. The generated SQLite preview updates as you work.
SQLite preview.nodeql


03
Run and inspect
Connect a database, execute the query, and inspect its results. Copy the generated SQLite command.
SQLiteCopy command









05 / Learn SQL


Learn the shape of a query
before the syntax.


Build queries with plain-language blocks in Simple mode or switch to standard SQL labels in Advanced mode. Preview the generated SQLite and save or share your work as a .nodeql project file.




Simple mode
Plain-language node labels such as “filter rows” help make query actions easier to understand.


Advanced mode
See standard SQLite labels such as WHERE, GROUP BY, and ORDER BY on the same query blocks.


Run real queries
Execute against a local SQLite database and inspect results or SQLite errors in context.
